# Deutsch mit Bea

App per imparare il tedesco a livello B1/B2 (preparazione Goethe-Zertifikat): lezioni, vocabolario con voce, giochi, ascolto, pronuncia col microfono, tutor IA (Google Gemini, piano gratuito), allenamento IA e simulazione d'esame.

App installabile (PWA) per Windows e iOS. Viene pubblicata con GitHub Pages. Piano e dettagli: [PIANO.md](PIANO.md).
